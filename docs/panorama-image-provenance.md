# Panorama image provenance (SP1)

SP1 ships **one placeholder 360° tour** on the `macquarie-theatre` venue, flagged
in-UI as **"Demo 360° — sample imagery, not this venue"**. This records the
rights basis for every bundled panorama image.

**Rights basis:** aon2026 and MQ_Journey are sibling projects under the same
owner (MQ). These photos are reused with that owner's permission as *temporary
placeholder/demo* content, downscaled. They depict a **different building**
(10 Hadenfeld Ave), which is why the UI flag states the imagery is not the
venue. **They must be replaced with real, owned 360° photos of Macquarie
Theatre before any public release.** If that permission is ever in doubt,
substitute owned or CC-licensed demo panoramas (the viewer is content-agnostic —
no code change).
